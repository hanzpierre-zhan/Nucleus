Hola, te comparto la propuesta para implementar una plataforma web SaaS que permita centralizar información, consolidar evidencias y exportar expedientes para varios usuarios.

- Importación de datos (Excel/CSV)
- Gestión de usuarios y roles
- Consolidación de evidencias
- Exportación de expedientes
- Dashboard y reportes
- Hosting, base de datos y almacenamiento incluidos

Implementación inicial:
- S/ 27,000 sin IGV

- Total mensual con IGV: S/ 5,841

Infraestructura primer año:
- Render + Neon + Backblaze B2: S/ 9,000

- Desarrollo e implementación

No incluye:
- Migración masiva de datos históricos
- Integraciones con sistemas externos
- Funcionalidades adicionales fuera del alcance
