Alcance y configuración de capacidad

Se consulta el servicio Render configurado, la base PostgreSQL conectada y el bucket B2 configurado. No representa toda la cuenta ni confirma disponibilidad externa.

Define los presupuestos de tu plan en Environment: RESOURCES_RENDER_MEMORY_MB, RESOURCES_NEON_STORAGE_MB y RESOURCES_B2_STORAGE_MB. Sin ellos se muestra “Sin presupuesto”; no se inventan porcentajes. Son umbrales de seguimiento, no límites oficiales de facturación.

RAM y CPU se leen del contenedor. CPU muestra el promedio entre lecturas (la primera usa una muestra breve). El disco temporal corresponde al sistema de archivos visible; no es almacenamiento B2 ni una cuota contratada. Tráfico, facturación y otras ramas se revisan en las consolas. B2 incluye versiones anteriores y limita el inventario a 10 páginas; señala cuando es parcial.

El reporte JSON incluye fecha, fuentes, mediciones y prioridades. Caché compartida por worker durante 60 segundos. Cada reporte es una captura; no se almacena historial permanente.
